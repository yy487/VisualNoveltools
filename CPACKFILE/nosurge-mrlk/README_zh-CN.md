# Ciel nosurge DX MRLK 解包封包工具

`nosurge-mrlk` 用于查看、解包和重新封装 **Ciel nosurge DX** Windows 版的
`MRLK` 资源包。这些文件虽然常用 `.psarc` 扩展名，但并不是真正的 Sony
PSARC，所以普通 PSARC 工具无法处理。

工具会检查完整文件头、文件表、CRLF 文件名表、数据范围和输出路径。包内
G1T 等文件按原始字节直接复制；G1T 与图片之间的转换请继续使用专门的 G1T
工具。

## 最简单的用法

双击 `nosurge-mrlk.exe`，或把 MRLK `.psarc` 文件拖到 EXE 上，然后在菜单中
选择：

```text
1) 查看文件表
2) 解包
3) 封包
0) 退出
```

交互模式会先显示并允许修改输入、输出和覆盖选项，最后确认后才会写文件。

命令行用法：

```text
nosurge-mrlk list <原包.psarc> --limit 20
nosurge-mrlk unpack <原包.psarc> <解包目录>
nosurge-mrlk pack <原包.psarc> <编辑后目录> <新包.psarc>
```

推荐流程：

```text
1. 把 ui_tex.psarc 解包到一个新的目录，例如 ui_tex_unpacked。
2. 用 G1T 工具转换、编辑并重新生成需要替换的 G1T。
3. 按原相对路径和文件名放回 ui_tex_unpacked。
4. 封包时选择未改动的 ui_tex.psarc 作为模板。
5. 输出为新文件，例如 ui_tex_repacked.psarc，先测试再替换游戏资源。
```

封包必须提供原包作为模板，因为工具会原样保留其文件名表和文件顺序，再根据
编辑后文件的实际大小重建全部绝对偏移和大小。文件可以变长或变短。目录里与
模板无关的额外文件会被忽略；模板列出的文件缺少任何一个都会停止，且不会留下
半成品。

工具绝不会覆盖作为模板的原包。其他已存在输出也会默认拒绝；只有命令行加入
`--overwrite` 或在交互模式明确同意后才会替换。新包会先在临时文件中完整生成并
验证。

## 编译

安装当前稳定版 Rust 后，在源码目录运行：

```text
cargo build --release
```

生成的程序位于 `target\release\nosurge-mrlk.exe`。

## 已确认的格式范围

- 24 字节小端文件头：`MRLK`、必须为零的保留字段、文件表结束位置、文件数、
  文件名表位置和大小。
- 每项 8 字节：绝对文件偏移和文件大小，均为 32 位。
- 文件名以 CRLF 分隔并结尾；已检查的游戏文件名全部是 ASCII。
- 数据连续存放，包层没有加密、压缩或对齐填充。
- 重新封装受格式的 32 位偏移和大小上限限制。
- 游戏中另有一个真正以 `PSAR` 开头的样本，它属于不同格式，本工具不处理。
