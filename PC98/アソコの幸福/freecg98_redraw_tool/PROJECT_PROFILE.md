# 项目档案：PC-98 FREECG98 字体

## 已确认结构

- 格式：Windows BMP，2048x2048，1bpp，BI_RGB，bottom-up。
- 像素区偏移：62 字节；行跨度：256 字节。
- 调色板：索引 0 为黑，索引 1 为白。
- 字形槽：16x16。
- 映射：3025 个简体目标到 3025 个唯一日文载体。
- 编码：载体必须严格编码为双字节 CP932，并转换到标准 JIS X 0208。
- 坐标：`tile_x = jis_row - 0x20`，`tile_y = jis_cell`。

## 资源策略

基础 BMP、映射 JSON 和 16x16 单色字形表都作为编译期资源内嵌。字形表由项目
所带 TTF 在 16 px 下经 FreeType 单色 hinting 生成，运行时不依赖字体安装、
FreeType DLL 或外部资源路径。运行时只收集输出路径和覆盖策略。

## 修改策略

只清空并重绘映射所指的 3025 个槽；文件头、DIB、调色板、尺寸及映射外像素保持
原样。载体映射已经证明唯一、在界内且原槽非空，因此本版本不重新分配载体。
禁止恢复为未 hint 的轮廓缩放加 coverage 阈值方案；该方案会在 16 px 下造成宋体
笔画膨胀和粘连。

## 验证基线

- 映射条目：3025。
- 唯一槽位：3025。
- 原始非空映射槽：3025。
- `黑 -> 黒 -> 8D95 -> 3975 -> (25,117)`，原槽 79 黑像素。
- `赶 -> 骭 -> E98C -> 716C -> (81,108)`，原槽 79 黑像素。
- `应 -> 応 -> 899E -> 317E -> (17,126)`，批准字形 59 黑像素。
- 输出必须保持 524350 字节及原始 62 字节 BMP 头部。
- 3025 个映射槽必须逐像素等于内嵌字形表，`matching_slots=3025`。

## 未覆盖范围

不修改脚本编码、文本映射逻辑、模拟器配置和磁盘镜像；不为映射外字符动态分配
载体槽。虽然字形位图已有逐像素基准，最终字号观感仍需在目标模拟器内验收。
