# 夕焼け -November- MES 项目档案

## 路径与交付

- 游戏：夕焼け -November-
- 运行时：`yuyake.exe`，32 位 Windows 程序
- 样本：`..\mes`，共 134 个文件
- 工具目录：当前目录
- 工具语言：Rust
- 源脚本不覆盖；所有输出写入新文件或新目录

## 已确认格式

- `confirmed-runtime`：主解释器 `sub_40861C` 调用 `sub_409220` 读取 opcode。
- `confirmed-runtime`：`0x15` 的处理路径为 `sub_408DF0 -> sub_409DF4 -> sub_409E08`。
- `confirmed-runtime`：`sub_409E08` 读取小端 `u16` 页号，再由 `sub_403734` 读取 NUL 结尾字符串。
- `confirmed-runtime`：`sub_403734` 按 CP932 双字节首字节范围读取文本，并将 `03`/`04` 作为双字节控制序列首字节。
- `confirmed-runtime`：渲染函数 `sub_40AB94` 将控制码 `01` 作为换行，将 `02` 作为清屏/位置复位，将 `03` 忽略，将 `05` 交给显示等待相关处理。
- `confirmed-structure`：134 个文件中找到 3,157 个 `0x15` 页记录；每个文件内页号严格连续，文本严格 CP932 解码无失败。
- `opaque-preserved`：除 `0x15` 页记录外的 opcode 和数据不重建，注入时逐字节保留。

## 用户确认规则

- 本游戏没有独立 `name` 行。
- JSON 不输出或写回 `name`，也不根据引号、首行或显示效果猜测说话人。
- 只提取含正文的页；纯控制页不生成条目。
- 页内每个控制边界之间的句子独立生成一条 JSON 记录，使用 `scr_msg/message`；不把整页合并成数组。
- 页内控制码不暴露为可编辑文本，按每条记录的前后控制元数据定位并原样保留。

## 注入能力

- 策略：`in_place`。
- 译文不得超过原页字符串槽。
- 短译文只在差值为偶数时支持；使用运行时明确忽略的 `03 03` 对填满原槽。
- 奇数字节差、变长、控制布局变化、CP932 不可编码字符均拒绝。
- 不移动后续指令，不改跳转、页号、指针、表项或文件长度。

## 已知限制

- 未实现整套 VM 的结构化反汇编与变长重定位。
- `02` 的最终视觉效果由运行时路径确认到清屏/位置复位；工具只需无损保留，不依赖更细的视觉命名。
- `05` 的精确交互时机不影响无损处理，保持原字节与顺序。
